# NEXUS — Sistema de Simulación Táctica
Aplicación de escritorio en C# (.NET) orientada a objetos con persistencia en SQL Server, evolucionada desde una arquitectura de consola (Hito 3) hacia un entorno gráfico en Windows Forms.

## Tecnologías
- **Lenguaje:** C# (.NET 10.0)
- **Paradigma:** POO, Polimorfismo, Interfaces (`IActivable`), LINQ
- **Interfaz Gráfica:** Windows Forms (WinForms)
- **Base de Datos:** SQL Server (ADO.NET / T-SQL)

## Estructura del Repositorio
- `src/`: Código fuente de las clases de dominio y lógica.
- `docs/`: Documentación técnica del Hito 4 (Diseño de juego, arquitecturas, modelo de datos y análisis técnico).

## Ejecución
1. Clonar el repositorio.
2. Abrir la solución en **Visual Studio 2022**.
3. Compilar y ejecutar `Nexus.sln`.
